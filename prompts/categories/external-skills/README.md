# External Skills

> **Third-party capabilities** - Skills imported from the broader ecosystem (skills.sh)

This directory contains skills imported from external sources, adapted for use with the DgtlEnv prompt router.

## Overview

These prompts are adapted from the [skills.sh](https://skills.sh) ecosystem. They provide specialized capabilities like advanced git operations, bash expertise, and more.

## Naming Convention

External skills are renamed to follow the project standard:
`[original-name]-v1.0.0.md`
