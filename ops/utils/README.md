# Operations Utilities

This directory contains standalone utility scripts and helper tools used by the Ops system.

## Utilities
- `rag_retriever.py`: A Python script for Retrieval-Augmented Generation (RAG). It handles document tokenization, TF-IDF scoring, and retrieving relevant context for AI prompts.

## Usage
These scripts are typically called by other shell scripts in `scripts/` or `ops/` rather than executed directly by the user.
